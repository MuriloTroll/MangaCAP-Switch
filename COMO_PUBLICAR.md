# Como publicar a documentação

1. Abra seu repositório no GitHub.
2. Substitua o arquivo `README.md` da **raiz** pelo `README.md` deste pacote.
3. Adicione `GUIA_INICIANTE.md` também na **raiz**. Assim o link do README funciona.
4. Confirme que o GitHub exibiu o README formatado na página inicial.
5. Na Release `v1.0.0`, use o conteúdo de `RELEASE_v1.0.0.md` como descrição e anexe o `.nro` aprovado.
6. Não envie este ZIP como substituto do `.nro`: o ZIP contém somente documentação.

**Atenção:** se você substituir todo o repositório pelos arquivos do ZIP de código, o `README.md` antigo poderá voltar. Atualize o README depois de enviar o código.

Os atalhos Y/X de manutenção de capas foram removidos do código final, e por isso não aparecem como recursos na documentação.
