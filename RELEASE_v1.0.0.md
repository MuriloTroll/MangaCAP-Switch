# MangaCAP Switch v1.0.0 — Primeira versão pública 🎮📚

O **MangaCAP Switch** é um leitor gratuito de mangás e livros para Nintendo Switch com homebrew. Organize obras em uma biblioteca com capas grandes, leia na horizontal ou vertical, salve seu progresso e use uma biblioteca privada protegida por PIN.

**Formatos:** CBZ, PDF, EPUB e TXT. **Idioma:** português brasileiro.

## Destaques

- Biblioteca em grade com rolagem por toque e barra de posição.
- Orientação horizontal e vertical sem girar o sistema do console.
- Nome do arquivo visível nos controles durante a leitura.
- Atalhos Topo, Girar, navegação entre volumes, zoom e modo contínuo.
- PIN de seis dígitos e código de recuperação para a biblioteca privada.
- Apoio por Pix inteiramente opcional, via botão ❤️.

## Instalação em 4 passos

1. Baixe o arquivo **`MangaCAP.nro`** anexado a esta Release.
2. Copie-o para **`switch/MangaCAP.nro`** no microSD.
3. Coloque os arquivos de leitura em **`switch/MangaCAP/books/`**.
4. Inicie o aplicativo pelo **Homebrew Menu**.

Para instruções completas de **botões, atalhos, organização de volumes, biblioteca privada, criação e recuperação de PIN, transferência de arquivos e solução de problemas**, consulte o **README.md** na página principal do repositório ou o arquivo **`GUIA_INICIANTE.md`**.

**Atenção:** o MangaCAP não inclui mangás ou livros, não é afiliado à Nintendo e requer um console já configurado para executar homebrew. O apoio financeiro é voluntário; todos os recursos são gratuitos.
