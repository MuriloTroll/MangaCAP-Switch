# MangaCAP Switch v1.0.0 (candidato a lancamento)

Leitor gratuito de mangás e livros para Nintendo Switch. Suporta CBZ, PDF, EPUB e TXT, biblioteca em grade, leitura vertical e horizontal, progresso e biblioteca privada.

## Apoie o projeto

Na biblioteca principal, toque no coração vinho para exibir o QR Code Pix de contribuição opcional. Nos controles, pressione **L** para abrir a janela e **B** para fechar. O QR funciona offline, mas o pagamento exige o aplicativo do banco no celular. Confira o nome do recebedor antes de confirmar.

## Compilação

Use GitHub Actions, workflow **Build MangaCAP Switch**. O `.nro` é publicado em Releases como pré-lançamento `v1.0.0-rc-*`. Depois dos testes reais, crie a release pública `v1.0.0`.

Os documentos de testes antigos não são necessários para compilação. A exclusão dos arquivos no ZIP não os remove automaticamente do repositório remoto.
